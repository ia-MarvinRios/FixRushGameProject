## ✨ Descripción

**FixRush!** es un videojuego 3D multijugador de reparaciones de vehículos donde el jugador es el dueño de un taller y su meta es hacerlo crecer.

Diseñado con enfoque en:
- 🚗 Diferentes vehículos
- 🎃 Cooperación y Multijugador
- 🧠 Resolución de problemas
- 📈 Progresión del taller
- ⏰ Contra el tiempo
